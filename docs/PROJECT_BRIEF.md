# Project Brief

## Name
Pocket Passport

## Tagline
Your world, in your pocket.

## Category
Travel & Countries – country discovery.

## Target experience
A polished, responsive mobile app for discovering countries and keeping a personal favourites list.

## Assigned twist
Smart Search:
- Debounced search.
- Filter chips.
- Clear empty state.

## MVP screens
1. Login
2. Register
3. Home / Explore
4. Country Details
5. Favourites
6. Optional Profile / Settings (not a replacement for required screens)

## MVP success criteria
A user can register/login, browse countries, search with debounce, filter by region, view details, favourite/unfavourite countries, restart the app and still see favourites, and log out.

## Product scope guardrail
Do not expand the assignment MVP into a full travel social network before all assessed requirements are complete.

# Assignment Evaluation Rubric

| Criterion | Marks |
|---|---:|
| Authentication & validation (including secure token storage) | 15 |
| Navigation (auth flow, typed params) | 10 |
| API integration & data display (including loading/error/empty states) | 15 |
| State management & persistence | 15 |
| Assigned twist – Smart Search | 10 |
| UI/UX & responsiveness | 10 |
| Code quality & best practices (TypeScript, structure, lint, tests) | 15 |
| Git history, README & Key decisions | 5 |
| Demo video (app flow + technical walkthrough) | 5 |
| **Total** | **100** |

Bonus: up to +5 marks for one selected bonus feature:
- Dark mode toggle remembered after restart.
- Smooth Reanimated interaction.
- Component tests with React Native Testing Library in addition to the three required tests.
